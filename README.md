# Student Grade Calculator using Python

## About the Project
This Python project calculates a student's total marks, average, grade, and final result.

## Technologies Used
- Python

## Features
- Takes student name as input
- Accepts marks in three subjects
- Calculates total and average marks
- Assigns a grade based on average marks
- Displays PASS or FAIL
